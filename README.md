*Hello everyone!*

What is V-Power? you might ask. Well, V-Power is a mini handheld console/camera

The main MCU is a XIAO ESP32-S3 Sense with an OV3660 camera sensor. It have an OLED 0.96" display with 4 buttons, a rotary encoder and 2 led


There are 3 modes
  1. Menu
  2. Game
  3. Camera
  4. Gallery
